The first independently useful acceptance demonstration is phases 2–4: incident journal → private owned history → credible text-only evidence → user-controlled consumer action. Phase 7 is deliberately not a dependency of phase 4. Phase 6 adds measurement history without requiring uploads. Public intelligence may display insufficient publishable data until release gates pass; never fill gaps with demo observations.

Codex coordinates contracts/backend/integration; Antigravity reviews contracts then owns frontend implementation. Work may overlap only when dependencies/contracts are accepted and file ownership is isolated; no two writers on schema/contracts. Each phase report must identify exact files, approved versions, command outputs, negative tests, known limitations and unrun checks. Security-critical changes need reviewer identity/tool actually used, revision reviewed, attack scenarios and disposition before integration. No tests above are claimed to have run during this mission.
